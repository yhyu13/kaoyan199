# 接入指南 · 把资料接进知识库（含 DeepSeek 对话）

> 你要的东西只有一句：**把资料整理成 JSONL，丢进 `10-真题体系/知识库/`，跑一条命令。**
> 双链、反向链接、图谱都是构建时算出来的，你只要写 `[[…]]`。

---

## 零、三条命令够用了

```bash
cd "C:/Git-repo-my/2026考研/10-真题体系"
python _data/kb.py import handoff.jsonl --agent "星际绘画"   # 批量入库
python _data/kb.py check                                    # 断链 / 歧义 / 孤立
python _data/kb.py build                                    # 重建 index.html
```

`build` 会打印：`N 条手记 / M 个考点 / K 道真题 / 边 E 条 / 待建 D 个`。**D 必须是 0**（除非你确实想留个待建）。

## 一、DeepSeek 对话怎么进来（专栏 `deepseek`）

### 路线 A：丢给 Chat（推荐）

把 **分享链接 + 对话正文** 粘进对话，说「收进知识库」。我做的事：

1. 剥掉寒暄和重复，留下**真正的结论**；
2. 一条结论一条记录（不把两小时对话塞成一条）；
3. 每条挂上 `[[双链]]`，指回相关考点（`[[判别式]]`）和题（`[[第9题]]`）；
4. 原文整段折叠在条目底部，随时翻得回原话；
5. 跑 `check` + `build`，把断链修掉。

### 路线 B：自己跑命令

```bash
python _data/kb.py ds \
  --url "https://chat.deepseek.com/share/xxxx" \
  --file 对话.md \
  --title "结论句，不是「关于…的讨论」" \
  --take "这次真正留下的一句话" \
  --reject "被推翻的那个说法" \
  --tags "逻辑,削弱" \
  --questions "37"
```

`--file` 里认这些标记（中英都行）：

```
我：……            DeepSeek：……
用户：……          助手：……
**我**：……        **AI**：……
Q: ……            A: ……
```

认不出来就整段当原文塞进折叠区，不会丢内容。

产出长这样（`body` 骨架固定，就是为了这一栏的条目能对比着看）：

```markdown
> 来源：DeepSeek 对话 · 2026-11-16 · [原对话](https://chat.deepseek.com/share/xxxx)
> 采集：manual

## 我问的
（原提问，不改写）

## 采纳的结论
（一句话）

## 没采纳 / 被推翻的
（原来怎么想的，为什么被推翻）

## 相关
（`[[双链]]` 写这里，或者直接写进上面几节）

<details><summary>原文（8421 字）</summary>
…
</details>
```

## 二、如果你能写文件（同一台机器）

### 第 1 步：拆条，产出 `handoff.jsonl`

```jsonl
{"kind":"method","title":"削弱题先看『量』再看『可能』","column":"logic","summary":"量化否定强于可能性","tags":["逻辑","削弱","通解"],"source":{"agent":"星际绘画","url":"https://chat.example/x"},"refs":{"questions":["37"]},"body":"结论链是 `资本下乡 → 地租 → 富裕`。\n\n- 只占一小部分 → 强（量化否定）\n- 可能会 / 也许 → 弱\n\n对照 [[削弱题]] 与 [[第37题]]。"}
{"kind":"mistake","title":"我把『证明不了』当成『不存在』","column":"logic","summary":"诉诸无知的变体，削弱题里栽过两次","tags":["逻辑","削弱","错因"],"source":{"agent":"星际绘画"},"body":"题干说「没有证据表明 A 导致 B」，我直接判 A 不导致 B。\n\n正确读法：没有证据 ≠ 证据表明没有。\n\n相关：[[我把「证明不了」当成「不存在」]]"}
```

**一个文件里放多少条都行**，一条一个 `\n`。首行可以写 `# 注释`，会被跳过。

### 第 2 步：跑导入

```bash
python _data/kb.py import handoff.jsonl --agent "星际绘画"
```

输出：`导入 N 条：新增 X，重复 Y`。

### 第 3 步：验收

```bash
python _data/kb.py check          # 断链必须为 0
python _data/kb.py list -n 20     # 终端里看
start 知识库/index.html            # 浏览器：条目 / 专栏 / 图谱
```

## 三、双链怎么写才连得上

| 想连到 | 写法 | 备注 |
|---|---|---|
| 另一条手记 | `[[那条的标题]]` | 标题必须一字不差；嫌长就给它加 `aliases` |
| 别名 | `[[和与积]]` | 对方条目里有 `"aliases": ["和与积"]` |
| 考点 | `[[判别式]]` `[[削弱题]]` | 按标题 / 短标签 / 唯一前缀匹配 |
| 指定考点 id | `[[kp:discriminant]]` | 最稳，不怕重名 |
| 真题 | `[[第37题]]` `[[q37]]` `[[37]]` | 三个写法等价 |
| 母题 | `[[T9]]` | 母题没有独立页面，只在图里亮 |
| 外部网页 | `[文字](https://…)` | 普通 Markdown 链接，不进图谱 |

**写错了会怎样**：图谱里出现红色「待建」节点，`check` 会把标题和来源列出来，页面的「条目」页底部还给你一行可复制的 JSONL 骨架。不会静默失败。

## 四、什么样的内容值得入库

| 值得 | 不值得 |
|---|---|
| 一类题的**通解**（判据、下手顺序、失效条件） | 单道题的完整抄题（题面已在题库里） |
| **错因**：我当时怎么想的、正确识别信号是什么 | 「今天学了逻辑」这种流水 |
| 与 Agent 对话里**推翻过的结论**（含原文） | 未经核实的传言 |
| 外部资料的**关键结论 + 链接** | 整篇转载 |

判据一句话：**半年后你还会翻它吗？** 不会就别入库。

---

## 五、我们能接受的边界

- 条目数：单次导入 ≤ 500 条（再多分批）
- 单条正文：≤ 60000 字符
- 图片：给 URL 或本地绝对路径，不要 base64 塞进 body
- 去重：`sha1(title + body)`，**同一标题同一正文重复导入不会新增**
- **只追加不改写**：已经入库的条目不要改历史。要修正，就新开一条并在正文里 `[[旧的那条]]` 说明——图和反链才留得下痕迹

## 六、出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| `✗ 条目校验失败：… kind 必须是 …` | kind 拼错 | 按提示改成 7 个枚举之一 |
| `⚠ 第 N 行不是合法 JSON，已跳过` | 某行折行了或少了引号 | 修那一行，重跑整个文件（已入库的会自动去重） |
| `✗ 断链 N 个` | `[[…]]` 里的标题和已有条目不匹配 | 改成真标题，或把那条建出来 |
| 图谱里多出一个灰红点 | 同上的断链 | 同上 |
| 导入后 `index.html` 没变化 | 忘了 build | `python _data/kb.py build` |
| 反链里没看到我 | 你只在 `refs` 里加了题号，正文没写 `[[…]]` | 反链只统计正文里的双链 + refs；`refs` 类链接的上下文是 `summary` |
| 一条内容归错专栏 | 没写 `column`，按 `tags[0]` 归类了 | 补 `column`，或把 `columns.json` 里的名字和标签对齐 |

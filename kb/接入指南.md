## 一、如果你能写文件（同一台机器）

### 第 1 步：把材料拆条，产出 `handoff.jsonl`

一行一个 JSON 对象。字段见 `schema.md`，最小可用是 `kind + title + body`。

```jsonl
{"kind":"method","title":"地图题的四个下手位置","summary":"顶点→边界→内部→交叉","tags":["逻辑","分析推理"],"source":{"agent":"星际绘画","url":"https://chat.example/x"},"refs":{"questions":[]},"body":"1. 顶点：先把确定数值的点填满\n2. 边界：只与一个点相邻的格子\n3. 内部：自由度最高的先留\n4. 交叉：一拖二题的公共题干"}
{"kind":"mistake","title":"我把「证明不了」当成「不存在」","summary":"诉诸无知的变体，削弱题里栽过两次","tags":["逻辑","削弱","错因"],"source":{"agent":"星际绘画"},"body":"题干说「没有证据表明 A 导致 B」，我直接判 A 不导致 B。\n正确读法：没有证据 ≠ 证据表明没有。"}
```

**一个文件里放多少条都行**，一条一个 `\n`。

### 第 2 步：跑导入

```bash
cd "C:/Git-repo-my/2026考研/10-真题体系"
python _data/kb.py import 你产出的 handoff.jsonl --agent "星际绘画"
```

输出会告你：`导入 N 条：新增 X，重复 Y`。

### 第 3 步：看结果

```bash
python _data/kb.py list -n 10        # 终端里看
start 知识库/index.html               # 浏览器里看（数据内联，断网也能开）
```

`index.json` 是给机器读的（含 count / kinds / tags / entries 摘要）。

## 二、如果你不能写文件（只能产出文本）

在你的回复里输出**一个 ```jsonl 代码块**，人复制保存成 `handoff.jsonl` 即可。

要求：

- 每个对象单独一行，**不要换行折行**（`body` 里的换行写成 `\n` 转义）
- 不要包外层数组（要么纯 JSONL，要么一个 JSON 数组，两种 `kb.py import` 都吃）
- 块的第一行写一句注释说明来源：`# 来源：星际绘画 / 2026-11-11`

## 三、可以直接粘给别的 Agent 的指令

> 你在帮我整理 199 管综备考资料。请把下面的材料拆成若干条知识库条目，用 JSONL 输出（每行一个 JSON 对象，不要数组、不要折行）。
>
> 字段：`kind`（method 通解 / question 单题解析 / mistake 错因 / link 资料 / image 图 / dialog 对话 / note 杂项）、`title`（≤120 字，**必须是结论句**，不要用「关于…的讨论」）、`summary`（≤200 字）、`body`（Markdown，可用 `$LaTeX$`）、`tags`（2–4 个，第一个用学科）、`source.agent`、`refs.questions`（涉及的题号，如 `"9"` 或 `"T1"`）。
>
> 硬规则：① 一条只讲一件事，一段对话里有几个结论就拆几条；② 标题写结论不写话题；③ body 独立可读，不要写「如上所述」；④ 不放个人信息与付费资料全文。
>
> 输出格式：一个 ```jsonl 代码块，第一行 `# 来源：<你的名字> / <日期>`。

## 四、什么样的内容值得入库

| 值得 | 不值得 |
|---|---|
| 一类题的**通解**（判据、下手顺序、失效条件） | 单道题的完整抄题（题面已在题库里） |
| **错因**：我当时怎么想的、正确识别信号是什么 | 「今天学了逻辑」这种流水 |
| 与别的 Agent 对话里**推翻过的结论**（含原文） | 未经核实的传言 |
| 外部资料的**关键结论 + 链接** | 整篇转载 |

判据一句话：**半年后你还会翻它吗？** 不会就别入库。

---

## 五、我们能接受的边界

- 条目数：单次导入 ≤ 500 条（再多分批）
- 单条正文：≤ 60000 字符
- 图片：给 URL 或本地绝对路径，不要 base64 塞进 body
- 去重：`sha1(title + body)`，**同一标题同一正文重复导入不会新增**

## 六、出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| `✗ 条目校验失败：… kind 必须是 …` | kind 拼错 | 按提示改成 7 个枚举之一 |
| `⚠ 第 N 行不是合法 JSON，已跳过` | 某行折行了或少了引号 | 修那一行，重跑整个文件（已入库的会自动去重） |
| 导入后 `index.html` 没变化 | 忘了看时间戳 | `python _data/kb.py build` 手动重建 |
